# Раскраска (Nuxt 4)

Веб-версия детской раскраски. Проект в разработке; полный README (архитектура, модель хранения, ограничения, доступы, работа с ИИ) будет к сдаче.

## Локальный запуск

Требования: Node.js 24 (`nvm use`), pnpm 10 (`corepack enable pnpm`).

```bash
pnpm install
pnpm dev            # http://localhost:3000
```

## Проверки

```bash
pnpm typecheck      # vue-tsc через nuxi
pnpm lint           # ESLint (+ границы слоёв)
pnpm lint:css       # Stylelint (mobile-first: только min-* медиа)
pnpm test           # Vitest: unit + nuxt
pnpm test:e2e       # Playwright: телефоны в альбомной ориентации, планшет, desktop
```

WebKit-проекты Playwright на Windows локально выключены: WebKit под Windows применяет системное масштабирование экрана к эмулируемому viewport. В CI (Linux) они работают; локально включаются через `PW_WEBKIT=1`.

## Структура

```
layers/core/       общая платформа: оболочка, «игровой режим», реестр игр
layers/coloring/   мини-игра «Раскраска»
shared/            типы и утилиты, общие для клиента и сервера
tests/             unit, nuxt, e2e
```

Игры регистрируются через `app.config.ts` своего слоя (`games.<id>`). Core строит навигацию по реестру и не импортирует код игр, это проверяет ESLint.

## Решения и допущения

- **Импорт SVG выполняется на сервере и не хранит исходную разметку.** Файл превращается в собственный формат: области (`region`) и линии (`ink`) с проверенными данными путей. Скрипты, ссылки, внешние ресурсы и DTD отбрасываются по построению.
- **Что считается областью.** Светлая заливка, а также замкнутый контур без заливки (типичный рисунок пером в Figma). Тёмные заливки (яркость ≤ 0.2) и обводки считаются линиями рисунка. Первая фигура на весь холст (заливка фрейма Figma) становится фоном: его можно красить, но в прогресс он не входит.
- **Линии поверх краски.** Рисунок накладывается на слой краски в режиме `multiply`: контур всегда виден, а исходный порядок слоёв сохраняется.
- **Кошка и дом** нарисованы для проекта вручную (в макете есть только осьминог). Их заменим на оригиналы, если они появятся.

## Известные ограничения

- Область задаётся замкнутой фигурой. Линии, которые визуально делят фигуру, отдельных областей не создают.
- Текст, растровые картинки, градиенты, маски и фильтры не поддерживаются: при импорте пользователь видит предупреждение, градиенты заменяются сплошной заливкой.
- Лимиты импорта: 1 МБ, 3000 элементов, 500 областей.
